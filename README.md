# 色序桌面助手 / ColorDesk

保留 Android 原生桌面的颜色整理工具，当前版本 **0.2.0 自动识别实验版**。

公开仓库：[guoguo1665204/ColorDesk](https://github.com/guoguo1665204/ColorDesk)。
安装包：[v0.2.0 实验版](https://github.com/guoguo1665204/ColorDesk/releases/tag/v0.2.0)。
本项目采用 [MIT 许可证](LICENSE)，欢迎提交问题反馈和改进。

## 自动识别

截图后读取桌面节点，按应用名称匹配图标。优先使用图像节点的实际边界，其次以本地图像边缘修正框选；根据检测坐标推断行列，同时保留每个图标的独立坐标，不再强行套用等间距格子。

识别成功后直接显示图标框和应用名称，手动校准默认折叠。可拖动框微调，或重新应用自动识别结果。只有图像候选时，不会自动选为可移动应用。

没有检测到图标的位置不等于空位，仍需用户确认真实空位。文件夹、组件、底部常用栏和抽屉节点按已知标识排除，但仍需检查结果。

“导出识别报告”可保存节点名称、边界、设备信息和识别结果，不含截图。报告包含桌面应用名称，仅在愿意分享时发送。

## 已实现

- Android 11–16 的源码支持范围，compileSdk / targetSdk 36。
- 检测默认桌面，显示品牌适配配置与无障碍连接状态。
- 用户主动截取当前桌面页，截图只在进程内存中处理。
- 自动识别图标位置、推断行列、支持独立图标框；保留手动校准。
- 用户标记普通图标、固定格子与真实空位。
- 从截图图标中央区域提取主色，生成颜色排序与网格预览。
- 使用空位交换图标，固定格子不参与移动，空位最终回到原位置。
- 连续长按与拖动，第一次只执行一步；核对通过后可逐步继续或执行剩余计划。
- 每步移动前后截图核对；桌面切换、方向变化、图标不符等情况停止。
- 运行时显示停止按钮。

## 兼容状态

本项目**尚未在真实手机上验证**。OriginOS、HyperOS/MIUI、ColorOS、One UI、EMUI/MagicOS、Pixel/AOSP 配置目前仅区分等待时间，不能视为已经适配成功。未知桌面使用通用实验配置。

兼容对象是“桌面应用 + 系统版本 + 布局”，而不是仅依据手机型号。iQOO Neo9 / Android 16 / OriginOS 6 是首个建议实测组合。

当前支持单页按行列排列的普通图标，行列间隔可不等距。文件夹和组件需检查并保留固定。不支持跨页、抽屉、文件夹内部、大幅不同尺寸图标、无法读取桌面窗口包名的启动器和非 Android 设备。

颜色来源是截图中校准框的中央区域，不是完整图标分割；多色图标、透明图标与主题可能影响主色。用户必须检查预览。视觉核对是保守的像素指纹比较，不能保证识别所有异常，也不能代替实机适配。

## 手机使用

1. 安装调试 APK。软件不会替换默认桌面，不需要 Root。
2. 关闭原生桌面的布局锁定，使用静态壁纸；先选择一个只有几个普通图标的测试页面，并预留一个空位。
3. 在工具中阅读权限说明，进入无障碍设置开启“色序桌面助手”。如果系统提示侧载应用受限，按照该手机系统提示处理。
4. 点击“截取当前桌面页”。工具返回桌面并显示浮层；切换到要整理的页面，点击“截取此页”，随后回到校准界面。
5. 等待自动识别，检查框和应用名称。可拖动框微调；失败时导出报告或展开手动校准。调整行列或滑块会退出自动定位并清除标记。
6. 按名称匹配的应用默认标为图标，图像候选和未确定位置默认固定。选择“空位”后点按真实空位；自动模式下可直接指定网格外的空位。识别到应用的位置不能当作空位；没有空位时先在桌面腾出位置后重新截图。
7. 生成预览。检查图标裁剪、主色与顺序，然后进入试运行。
8. 回到桌面后，先切换到截图对应的页面，再在浮层点击“试运行一步”。通过核对后可继续一步或执行剩余。执行期间不要触摸桌面或翻页，可随时按“停止”。

停止或失败后，已经发生的移动会保留。**没有自动撤销功能**，需要重新截图检查当前布局。相似图标、动态小组件、动态壁纸、桌面自动补位等可能导致停止。不能确认布局时，本版本不执行拖动。

## 构建

使用 JDK 17、Android SDK Platform 36、Build Tools 35.0.0、Gradle 8.13。

用 Android Studio 打开此目录，等待 Gradle 同步；也可设置 `JAVA_HOME`、`ANDROID_HOME` 后执行：

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug :app:lintDebug
```

项目使用 AGP 8.13.2、Kotlin 2.1.20。仅依赖 Android 原生界面与 API；测试使用 JUnit 4。没有网络权限、广告 SDK、云端识别或后台上传。

## 代码结构

| 文件                    | 用途                   |
| --------------------- | -------------------- |
| `MainActivity.kt`     | 权限说明、校准、格子标记、排序预览    |
| `DesktopModel.kt`     | 网格坐标、截图指纹、会话、桌面参数    |
| `DesktopService.kt`   | 桌面截图、浮层、连续拖动、逐步核对    |
| `core/ColorRank.kt`   | 主色提取与彩虹顺序            |
| `core/MovePlanner.kt` | 基于空位的移动计划            |
| `CoreTest.kt`         | 随机排列、不占用非空格、不丢失图标等测试 |

新增核心文件：`core/LayoutDetection.kt` 负责节点匹配、定位与行列推断；`core/ImageIconDetection.kt` 负责本地边缘候选检测；`DetectionTest.kt` 负责识别回归测试。

参考：[Android 无障碍服务](https://developer.android.com/guide/topics/ui/accessibility/service)、[节点屏幕边界](https://developer.android.com/reference/android/view/accessibility/AccessibilityNodeInfo)、[连续手势](https://developer.android.com/reference/android/accessibilityservice/GestureDescription.StrokeDescription)、[AGP 8.13](https://developer.android.com/build/releases/agp-8-13-0-release-notes)。
